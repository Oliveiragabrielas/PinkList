
# 🎀 PinktList — Lista de Compras

Aplicativo de lista de compras desenvolvido com **React Native, Expo e TypeScript**, com design delicado nas cores branco e rosa.

## ✨ Funcionalidades

* Adicionar produtos e quantidades.

* Remover itens da lista.

* Validar campos preenchidos.

* Interface simples e intuitiva.

## 🛠️ Tecnologias

* React Native

* Expo

* TypeScript

## 📚 Aprendizados

Durante o desenvolvimento, são trabalhados conceitos como:

Criação e reutilização de componentes.
Gerenciamento de estados com useState.
Renderização de listas com FlatList.
Manipulação de eventos.
Validação de formulários.
Organização de arquivos em um projeto React Native.

## 🚀 Como executar

```
npm install
npm run web
```
